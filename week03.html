10 When it breaks

The page opens, but the list is empty

Open the browser Console with F12. A syntax error in app.js stops the file before render() runs. Also check that index.html, style.css, and app.js are in the same folder.

I changed placements, but the page did not change

Changing the array does not redraw the screen by itself. Call render() after the change. In this exercise, every Add, Remove, or server result should end by rendering again.

Add works, but everything disappears after refresh

That is expected. The array exists only in browser memory. Refreshing reloads app.js from the top and recreates the original two placements. Persistent storage comes later.

Remove does nothing

Check the Console, then inspect the two important values: event.target and event.target.dataset.id. The dataset value arrives as text, which is why the starter converts it with Number(...) before comparing ids.

The server button immediately adds undefined

You are probably using the Promise instead of waiting for its result. The value returned by fakeServer() becomes the placement only after await resolves it.

Unexpected token or the rest of the file stops running

Look at the first red error in the Console. The real problem is usually on that line or immediately above it: a missing quote, parenthesis, brace, backtick, or comma.
