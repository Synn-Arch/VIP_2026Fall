Cool Choices / Website Building

Hello! Welcome to the Cool Choices tutorials.

You will place trees on a map, send them to a Python program that runs the SOLWEIG heat model, and see how the street-level heat changes — a complete web application.

How to use these tutorials

Each week is one page, and each page is written to be worked through in a single sitting of roughly two hours (hopefully!). Follow the steps in order. In the first weeks, you work alone to learn the basic concepts, and together to decide what the website should include. From Week 5 on, you work together as a team on one web application.

Every code block has a Copy button. Copying is fine and expected; you are learning to assemble a working system, not to type from scratch. Make sure that you understand what each piece does afterwards.

When something breaks, open the When it breaks section at the bottom of the page before searching elsewhere. The listed problems are the ones that actually happen in this stack, and the answers are specific to it.

What you will be using

The stack is fixed for everyone in the class. Every tutorial, starter file, and troubleshooting note assumes this exact set, so substituting a piece means you are on your own.

  • React with Vite — the interface you click on, written in JavaScript
  • Mapbox GL JS via react-map-gl — the map itself
  • Python with FastAPI — the program that receives your placements and runs the analysis
  • SOLWEIG-light — the heat model (mean radiant temperature and UTCI), running on an ordinary CPU, with GDAL and NumPy for the rasters
  • conda — the Python environment the model and the backend run in
  • A server — later in the semester, so the application has a public address. Until then, everything runs on your own laptop
  • Git and GitHub — how you save work and how you hand it in
