Spatial App · Tutorials 14 weeks

Fall 2026

Build a map that thinks.

You will place components on a map, send them to a Python program, and see the analysis come back — a complete web application, built one small piece at a time. No prior web development experience needed.

How to use these tutorials

Each week is one page, and each page is written to be worked through in a single sitting of roughly two hours. Follow the steps in order — later steps assume the earlier ones actually ran.

Every code block has a Copy button. Copying is fine and expected; you are learning to assemble a working system, not to type from memory. What matters is that you can explain what each piece does afterwards.

When something breaks, open the When it breaks section at the bottom of the page before searching elsewhere. The listed problems are the ones that actually happen in this stack, and the answers are specific to it.

Falling behind is survivable

Every week ships with a finished reference version of the previous week. If a week defeats you, take the finished copy, and rejoin. One bad week never locks you out of the course.

What you will be using

The stack is fixed for everyone in the class. Every tutorial, starter file, and troubleshooting note assumes this exact set, so substituting a piece means you are on your own.

  • React with Vite — the interface you click on, written in JavaScript
  • Mapbox GL JS via react-map-gl — the map itself
  • Python with FastAPI — the program that receives your placements and analyzes them
  • geopy and shapely — distance and geometry calculations
  • Vercel and Render — free hosting, so your application has a public address
  • Git and GitHub — how you save work and how you hand it in
